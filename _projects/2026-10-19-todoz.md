## Project Description

{{ page.description }}

ToDoz is a Todoist-style task manager for Windows, Android, Linux and the web. It keeps projects, sub-tasks, labels, priorities, recurring tasks, reminders, filters, and list, board and calendar views in a local SQLite database, so it works fully offline. Devices sync through a small self-hosted server with field-level merging, and data can be exported as CSV, ICS or JSON.

The design follows six principles: sovereignty, locality, predictability, responsiveness, focused interoperability and longevity. Recurrence and filters use a deterministic, rule-based parser rather than AI. ToDoz was built deliberately to embody these principles. AI coding agents lowered the cost of development, while the application itself contains no AI in its essential operations. See the blog post [ToDoz and the Rise of Personal Software]({% post_url 2026-10-19-todoz-personal-software-in-the-age-of-ai-agents %}) and the [philosophy](https://todoz.polla.dev/philosophy). The principles are published as a standalone [Sovereign Personal Software manifesto](https://sovereign.polla.dev/).
